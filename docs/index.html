Invoice Leash

An invoice-paying AI agent that stays safe when its model does not. The agent's code has no limit check, no vendor check and no signature check. Every limit lives on QoreChain, so we can hand the agent to an attacker and watch the chain say no.

Try to break it: attack lab (live, in your browser) Demo video (2:53) Code Threat model Verify it yourself MCP server Build Before Q-Day entry
3genuine invoices paid by a fully compromised agent (2.2 QOR)
8attempts refused, every one by the chain
0QOR to the attacker, ever (her full incoming history is checked)

Call scope

The agent may call InvoiceDesk.pay (0x38e5ab6a) and nothing else. No send, no approveVendor.

Value limits

1 QOR per payment, 2.5 QOR per day, 24 h expiry. QoreChain account abstraction, on the owner's own account: no vault.

Post-quantum invoices

ML-DSA-87 signature from an approved vendor whose key is registered on chain, checked by precompiles 0x…0a02 and 0x…0a01.
