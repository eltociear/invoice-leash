What you cannot try here, and why

  1. Send QOR straight to yourself. The agent's key is linked with permission evm only: refused on chain.
  2. Approve yourself as a vendor. The rule allows exactly 0x0027431D3314e672927eBfd9de57b1003198413b/0x38e5ab6a (InvoiceDesk.pay): refused on chain.
  3. Many small genuine invoices. 2.5 QOR per day: refused on chain.
  4. Those need the agent's key, so they live in the recorded runs and in npm run verify.
