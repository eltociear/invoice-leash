2. Run your own desk (your keys, this page)

Why there is no MetaMask button. On this chain an ordinary EVM wallet cannot send anything. We tried, with a fresh funded key, and QoreChain answered: “has no usable registered post-quantum key; the EVM lane requires one, like every other lane”. Every transaction needs an ML-DSA-87 key (the record).

So the console signs with your own hybrid keys (secp256k1 + ML-DSA-87), on your machine. Run the local signer, then open the link it prints. The page talks to it on 127.0.0.1, and your keys never leave your computer.

node desk.mjs init && node desk.mjs setup    # once: your company, your InvoiceDeskV3 (GETTING_STARTED.md)
node desk.mjs serve                            # prints: …/app.html#local=http://127.0.0.1:8742&token=…
